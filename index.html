Welcome to PDC!

This app helps concerned community-members gather, curate, and share public information.

Privacy by default: This app only saves your notes locally. We do not track you or connect to an external database. If you look up locations, search strings are proxied and not connected to any other data.

PublicDataCleanup is provided without warranty or guarantee. It is intended to support lawful gathering and analysis of public data. It should never be used to endanger, intimidate, or interfere with anyone, including legal law enforcement.

This app does not transmit data by default. All information stays on your device until you deliberately share it with someone. If you use mapping, your search text goes out to a geocoding + map service, but your tags and notes stay on this computer unless you share them.

Keyboard Shortcuts

Ctrl + Shift + / Open this window
Navigation + View
Tab Tab: Move between fields, options, and buttons.
Esc Escape: Deactivate the selected item or get out of a mode.
Ctrl + Shift + → Next Card: Move selection to the next card (wraps).
Ctrl + Shift + ← Prev Card: Move selection to the previous card (wraps).
Ctrl + Shift + 1-0 Target Card: Select card 1, 2, 3, 4...10.
Ctrl + Shift + V Toggle View: Cycle Notes → Split → Map.
Ctrl + Shift + G Go to Location: Focus map on selected note/card location.
Ctrl + Cmd + Shift + V Toggle Tab: Cycle Dispatch → Alert → Summary/Export → Settings → About / Legal.
Create New
Ctrl + Shift + N New Note: Create a new note in the selected card and focus it.
Ctrl + Shift + C
ORCtrl + Cmd + Shift + N New Card: Create a new card.
Set Location
Ctrl + Shift + L Set Location: Tag the selected card or note with a location.
Ctrl + Cmd + Shift + L Drop Pin Location: Start drag-pin location tagging for the selected card or note.
Search
Ctrl + Shift + S Search: Open search in Collect mode.
Card Actions
Ctrl + Shift + R Report: Toggle Report on the selected note.
Ctrl + Shift + M Min Card: Minimize the selected card.
Ctrl + Shift + P Card Color: Toggle through card color options for the selected card.
